# نظام تصاريح بوابات المركبات | Vehicle Gate Access Authorization System

تطبيق متكامل وخفيف بتقنية **HTML / CSS / JavaScript** متوافق 100% مع **Cloudflare Pages / Workers** وقاعدة بيانات **Cloudflare D1**.

مصمم بواجهتين مخصصتين:
1. **مدير المكتب (Office Manager - PC/Desktop)**: لإصدار التصاريح ومتابعة المركبات المباشرة بالداخل وتنبيهات التأخير وتصدير السجلات.
2. **حارس البوابة (Gate Officer - Mobile/Tablet)**: للبحث السريع عن لوحات المركبات العربية، مسح رموز الـ QR بالكاميرا، وتسجيل الدخول والخروج بلمسة زر واحدة.

---

## 🌟 أبرز المميزات (Key Features)

- 🌐 **دعم كامل للغة العربية (RTL) والإنجليزية (LTR)** مع زر تبديل فوري.
- 🚘 **محرك لوحات المركبات العربية**: يدعم لوحات المركبات الخليجية والسعودية والعربية (أ ب ج | 1 2 3 4) مع لوحة مفاتيح عربية مدمجة على الشاشة للجوال.
- 🎫 **إصدار تصاريح رقمية مع رمز QR**: إمكانية مشاركة التصريح مباشرة عبر واتساب مع السائق أو طباعته.
- 📷 **ماسح QR مدمج بكاميرا الجوال**: فحص فوري لتصريح السائق عند وصوله للبوابة.
- ⏱️ **عداد مدة البقاء وتنبيهات التأخير (Overstay)**: كشف فوري للشاحنات التي تجاوزت المدة المسموحة داخل المصنع.
- 📋 **القائمة المعتمدة والمحظورة (Whitelist / Blacklist)**: حظر فوري وتنبيهات أمنية للمركبات المخالفة.
- 📊 **تصدير السجلات والتقارير**: تحميل سجلات الدخول والخروج بصيغة Excel / CSV.

## 🔑 بيانات الحسابات (Accounts)

**لا توجد حسابات افتراضية محفوظة في الكود.** عند أول تشغيل، يتم عرض شاشة الإعداد الأولي لإنشاء حساب المدير.

| الدور / Role | الصلاحيات |
| :--- | :--- |
| **مدير المكتب (Manager)** | لوحة التحكم الكاملة، إصدار التصاريح، التقارير، إدارة الموظفين |
| **حارس بوابة (Officer)** | تفتيش اللوحات، تسجيل دخول/خروج بوابة محددة |

*(يتم إنشاء حسابات الحراس من خلال لوحة تحكم المدير)*

## 🚀 طريقة التشغيل المحلي (Local Running)

افتح الملف `index.html` في أي متصفح مباشرة، أو شغّل خادم محلي:

```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node / npx
npx serve .
```

ثم توجه إلى `http://localhost:8080`.

---

## ☁️ طريقة الرفع على Cloudflare (Cloudflare Deployment)

1. **إنشاء قاعدة بيانات D1 على كلاود فلير:**
   ```bash
   npx wrangler d1 create gate_access_db
   ```
2. **تطبيق جداول قاعدة البيانات (`schema.sql`):**
   ```bash
   npx wrangler d1 execute gate_access_db --file=schema.sql
   ```
3. **نشر الموقع على Cloudflare Pages:**
   ```bash
   npx wrangler pages deploy .
   ```
